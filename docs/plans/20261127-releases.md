# Releases

A release is an archive with the binary and the guest's `Image` and `rootfs.img`, published by CI from a merged `release: vX.Y.Z` PR as in vladkens' other repos (vladkens/actions), and a Homebrew formula in vladkens/homebrew-tap that follows it. Done when `make dist` makes the archive, the archive laid out as Homebrew installs it starts the VM on the test Mac without `LODKA_GUEST`, and the workflow passes actionlint and runs the checks and tests on every PR.

## Decisions

- The flow is vladkens/actions': `rust-build` with `dist: make dist` on a Mac, then `rust-publish` and `homebrew-bump` in `publish`, which never compiles. No crate on crates.io (`crates: false`) and no dev pre-release (`dev: false`): nothing is published but a merged release PR, which only the repo's owner releases.
- The guest is built on `ubuntu-24.04-arm`, as macOS runners have no Docker, only for release PRs, release commits and manual runs, and reaches the Mac's job as an artifact. The kernel is cached by its config, patches and build script.
- The archive, `lodka-vX.Y.Z-aarch64-apple-darwin.tar.gz`, has `lodka`, `Image`, `rootfs.img`, the readme and the licence at its top. The formula installs the binary in `bin` and the guest in `share/lodka`, where lodka looks next to its binary. The binary signs itself at its first start, as from a build: its folder in the Cellar is the user's.
- `homebrew-bump` only updates a formula: `lodka.rb` goes into the tap once, by hand, with the `HOMEBREW_REPO_TOKEN` secret in this repo.

## Tasks

- [x] 1. `make dist`; the archive, laid out as Homebrew installs it, starts the VM on the test Mac.
- [x] 2. The workflow: checks and tests on every PR; the guest, the archive and the release on release PRs and commits; the formula bumped.
- [x] 3. The readme's install with Homebrew; the formula for the tap.

## Checks

- `make check`, `make test`; actionlint on the workflow.
- On the test Mac: `make dist`, the archive unpacked into `bin` and `share/lodka` of a temporary prefix, `lodka start` without `LODKA_GUEST`, `docker run`, `lodka stop`.
